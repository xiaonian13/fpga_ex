# FPGA RGB 转灰度学习笔记

## 1. 核心算法

RGB 转灰度常用公式：

\[
Gray = 0.299R + 0.587G + 0.114B
\]

FPGA 中通常改成定点整数：

\[
Gray = rac{77R + 150G + 29B}{256}
\]

Verilog 写法：

```verilog
gray = (77 * R + 150 * G + 29 * B) >> 8;
```

其中 `>> 8` 相当于除以 256。

---

## 2. 三级流水线

```text
第1级：R×77、G×150、B×29
第2级：三路结果相加
第3级：右移8位得到灰度值
```

特点：

- 首个结果延迟约 3 个时钟周期；
- 流水线填满后，每个时钟可输出 1 个像素；
- 延迟是 3 拍，但吞吐率是 1 Pixel/Clock。

---

## 3. 有效信号对齐

```verilog
valid_d1   <= pixel_valid;
valid_d2   <= valid_d1;
gray_valid <= valid_d2;
```

作用：

- 把 `pixel_valid` 延迟相同拍数；
- 保证 `gray_valid` 与 `gray_data` 同时有效；
- `gray_valid = 1` 时，当前灰度数据才可使用。

---

## 4. 为什么没有使用 DSP

虽然代码中写了乘法：

```verilog
g_mult <= rgb_g * 150;
```

但因为：

- 输入位宽较小；
- 乘数是固定常数；
- 常数乘法容易拆成移位加法；

Vivado 可能不会使用 DSP，而是综合成：

```text
LUT + CARRY8 + FDCE
```

例如：

\[
150 = 128 + 16 + 4 + 2
\]

所以：

\[
G	imes150=(G\ll7)+(G\ll4)+(G\ll2)+(G\ll1)
\]

---

## 5. 左移和右移

### 左移

```verilog
A << n
```

相当于：

\[
A	imes2^n
\]

### 右移

```verilog
A >> n
```

对无符号整数相当于：

\[
A\div2^n
\]

固定移位在 FPGA 中通常只是重新布线，不需要复杂运算单元。

---

## 6. 综合网表中的主要器件

### IBUF

输入缓冲器。

```text
外部引脚 → IBUF → FPGA内部逻辑
```

每个输入位通常对应一个 IBUF。

### LUT

查找表，用于实现组合逻辑。

在常数乘法中负责：

- 生成局部逻辑；
- 实现加法条件；
- 配合进位链完成乘法。

### CARRY8

8 位高速进位链。

主要用于：

- 加法；
- 减法；
- 计数器；
- 常数乘法中的加法网络。

### FDCE

带时钟使能和异步清零的 D 触发器。

主要作用：

- 保存 1 位数据；
- 延迟 1 个时钟周期；
- 构成流水线寄存器；
- 在复位时清零。

---

## 7. 综合后的整体结构

```text
RGB输入
  │
IBUF
  │
LUT + CARRY8
  │
FDCE
  │
三路加法网络
  │
FDCE
  │
右移8位
  │
FDCE
  │
Gray输出
```

对应关系：

```text
IBUF：输入接口
LUT：组合逻辑
CARRY8：高速加法
FDCE：流水线寄存器
```

---

## 8. 最终结论

这段 RGB 转灰度代码综合后，是一条真实的硬件流水线：

```text
输入缓冲
→ 常数乘法
→ 加法
→ 右移
→ 输出
```

其主要特点是：

- 使用定点运算；
- 采用三级流水线；
- 数据和 valid 信号同步；
- 常数乘法可由 LUT 和 CARRY8 实现；
- 流水线填满后，每个时钟处理 1 个像素。
